Acerca de la aplicación
Tipo de aplicación

Es una aplicación full-stack para administrar un catálogo de celulares y sus marcas, con relación 1 a N (una marca tiene muchos celulares).

  • Frontend: aplicación de una sola página (SPA) desarrollada con Angular 22. Consume exclusivamente los endpoints del backend y permite hacer CRUD de celulares y marcas, filtrar, ordenar y paginar el listado.
  • Backend: API REST desarrollada con NestJS y TypeORM sobre PostgreSQL. Expone endpoints para celulares y marcas, con validaciones de negocio y manejo de errores.
Herramientas y programas utilizados
  • Lenguajes: TypeScript, HTML, SCSS, SQL.
  • Frameworks y librerías: Angular 22 (standalone components, HttpClient, Router), NestJS, TypeORM, pg (PostgreSQL), Bootstrap 5, RxJS.
  • Base de datos: PostgreSQL (corriendo en Docker localmente).
  • Herramientas: Node.js, npm, Angular CLI, Nest CLI, Docker Desktop, Docker Compose, Git, GitHub, Thunder Client / Postman, VS Code.

Proyecto desarrollado para la materia Tecnologías Web (TUARI, UNICEN).
